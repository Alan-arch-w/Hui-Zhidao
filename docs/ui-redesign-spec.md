# 汇知道 UI/UX 重新设计规格

## 1. 设计目标
- 去除常见 AI 产品的蓝紫色调与炫光感，呈现**政府政务的简洁、严谨**与**科技人才服务的时尚、克制**。
- 整体采用**深松绿 + 暖金色 + 暖灰白**的配色，强调可信赖、专业、有温度。
- 减少 emoji 与“AI”字样，使用“政策顾问”“智能服务”等更克制的表述。

## 2. 色彩系统
| 用途 | 色值 | 说明 |
|------|------|------|
| 主色深色 | `#0f3a32` | 侧边栏、重点按钮、深色标题 |
| 主色中 | `#2e7066` | 主要按钮、用户气泡、激活状态 |
| 主色浅 | `#f1f8f6` | AI 消息气泡、选中态背景 |
| 强调色 | `#c8a96e` / `#b39455` | 参考标签、 hover 高亮、装饰线 |
| 背景 | `#f7f6f2` | 页面暖灰白背景 |
| 表面 | `#ffffff` | 卡片、输入框 |
| 文字主 | `#1e293b` | 正文 |
| 文字次 | `#64748b` | 辅助说明 |

为减少改动范围，Tailwind 中通过覆盖 `blue` 色阶为松绿、`purple` 色阶为暖金，使现有 `blue-*` / `purple-*` class 自动映射到新色系。

## 3. 启动体验
- `vite.config.ts` 设置 `open: false`，避免 Vite 自身再打开浏览器。
- `start_huizhidao.py` 仍只打开一次 `http://localhost:5174`。
- 启动后仅弹出 **一个** 网页标签页。

## 4. 首页（HomePage）
- 全屏首页，在进入主应用前显示。
- 顶部大标题：汇知道 — 徐汇区人才政策服务助手。
- 登录区：手机号 / 邮箱 + 验证码输入框，点击“登录”即可进入，不要求真实后端验证，演示用。
- 数据展示：
  - 已收录政策：XX 条
  - 累计服务人才：XX 人
  - 成功对接项目：XX 项
- 背景：横向缓慢滑动的政策卡片墙，展示真实政策名称与一句话亮点，形成设计感且不喧宾夺主。
- 底部：徐汇区人才服务官方平台标识。
- 登录状态保存在 `localStorage`，刷新后无需重新登录。

## 5. 对话首页（Chat Empty State）
- 进入应用后默认进入“对话”模块，但不再直接出现一条消息。
- 居中显示：
  - 问候语：“你好，欢迎来到汇知道”
  - 副标题：“上传简历或输入问题，即可获取政策建议”
  - 两大操作卡片：
    - 上传简历（打开文件选择）
    - 直接提问（聚焦输入框）
- 下方展示 3–4 个引导气泡问题。

## 6. 对话输入区
- 移除原有“开始咨询”按钮。
- 输入框上方常驻“快速提问”气泡：
  - “我可以申请哪些人才补贴？”
  - “如何判断自己是否符合人才计划？”
  - “徐汇区有哪些创业扶持政策？”
  - “需要准备哪些申报材料？”
- 气泡点击后自动发送为一条用户消息，并触发 AI 回复。

## 7. 对话消息样式
- AI 头像改为纯色几何标识（HZ），不再使用 Sparkles 星星图标。
- AI 气泡背景改为主色浅色 `#f1f8f6`。
- 用户气泡背景改为主色深色 `#2e7066`。
- 保留现有富组件（简历上传、解析进度、画像卡、匹配结果等），只调整颜色映射。

## 8. 侧边栏
- 背景色改为 `#0f3a32` 深松绿。
- Logo 改为简约文字“汇”或几何标识，去掉渐变和星星。
- 图标 hover/激活态使用主色中 / 金色点缀。

## 9. 文案与图标
- 去除所有 emoji（✓、⊘ 等）替换为文字或图标。
- “AI 顾问”改为“政策顾问”“智能服务”。
- 将 `Sparkles` 图标替换为：
  - 头像/Logo：自定义几何标识或 `MessageSquare`
  - 解析按钮：`ScanLine`
  - 建议按钮：`Lightbulb`
