# 汇知道

汇知道是一套面向徐汇区人才政策场景的智能自查与申报准备助手。用户可以上传简历，补充关键资质信息，并获得政策匹配、条件缺口、材料清单、行动建议与完整分析报告。

## 项目背景

这个原型是在一次徐汇区 AI 创业相关活动中，用约 3-4 小时快速完成的。项目从人才理解政策成本高、申报条件分散、材料准备路径不清晰三个问题出发，将政策查询进一步设计为一条完整流程：

1. 上传并解析简历
2. 生成个人画像
3. 通过对话补齐信息
4. 匹配可能适用的政策
5. 汇总条件缺口与材料清单
6. 生成短期和中长期提升建议
7. 输出可阅读的完整分析报告

活动背景：[查看原始活动页面](https://mp.weixin.qq.com/s/mYQamx_fAvuIxbGY9eb7bw)

## 产品定位

汇知道不是官方审核系统，也不替代主管部门的最终认定。它的价值在于帮助申请者在正式申报前完成信息梳理、资格预判和材料准备，同时为人才服务人员提供更结构化的沟通起点。

## 技术结构

- React + TypeScript + Vite
- Tailwind CSS
- Framer Motion
- Express API
- DeepSeek 对话与简历信息提取
- Vercel 前端与 Serverless Function 一体化部署

## 本地运行

安装前端依赖：

```bash
npm install
```

安装服务端依赖：

```bash
npm --prefix server install
```

复制环境变量示例并配置模型密钥：

```bash
copy server\\.env.example server\\.env
```

分别启动服务端与前端：

```bash
npm run server
npm run dev
```

## 隐私说明

仓库不会提交本地环境变量、模型密钥、上传文件、依赖目录、日志与本地工具缓存。演示中的政策判断仅用于产品原型展示，具体条件以官方文件和主管部门审核为准。
